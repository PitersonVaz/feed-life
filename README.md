# FEED LIFE

A FEED LIFE é um projeto social criado com o objetivo de combater a fome e apoiar pessoas e famílias em situação de vulnerabilidade.

O site permite conhecer os projetos da ONG, consultar formas de doação e realizar cadastro para participar das ações.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Bootstrap
- Git e GitHub

## Estrutura do projeto

- `html` - páginas do site
- `css` - estilos da página
- `js` - funcionalidades em JavaScript
- `imagens` - imagens utilizadas no projeto

## Funcionalidades

- Navegação entre as áreas do site
- Exibição dos projetos da ONG
- Cadastro de usuários
- Registro de doações e voluntários
- Armazenamento de dados no navegador
- Recursos básicos de acessibilidade
- Navegação por teclado

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto.
3. Acesse a pasta `html`.
4. Abra o arquivo `index.html` no navegador.

## Acessibilidade

O projeto possui melhorias de acessibilidade, como navegação por teclado, indicação visual de foco, mensagens acessíveis no formulário e um link para pular diretamente para o conteúdo principal.
